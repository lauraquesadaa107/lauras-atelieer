# Laura’s Atelier — Web académica ficticia

Sitio estático HTML/CSS/JS listo para GitHub y Vercel.

## Páginas
- `index.html` — inicio animado con bolso y etiqueta LA
- `servicios.html` — catálogo de 12 bolsos en 4 colecciones, filtros y favoritos
- `wishlist.html` — favoritos guardados en `localStorage` del navegador
- `contacto.html` — email y teléfono proporcionados

## Publicación
1. Extrae los archivos del ZIP.
2. Sube todos los archivos (no el ZIP) a la raíz de un repositorio público de GitHub.
3. En Vercel, New Project → Import repository → Framework Preset: Other → Deploy.
4. Comprueba las páginas, imágenes, favoritos y HTTPS.

## Notas
- Las fotografías se cargan de Unsplash y requieren conexión a Internet; revisa que estén disponibles antes de entregar.
- Los bolsos y precios son ficticios. No hay compras ni pagos.
- Los favoritos se guardan solo en el navegador actual y pueden desaparecer si se borran los datos del sitio.
- El enlace de contacto abre el programa de correo; no hay formulario ni servidor de envío.
- El proyecto es académico y no comercial; consulta las condiciones del plan Hobby de Vercel.
